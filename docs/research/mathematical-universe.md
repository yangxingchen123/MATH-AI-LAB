# Mathematical Universe Foundation v0.1

MATH-AI-LAB 开始从知识管理，补一层 **数学发现基础设施** 的投影。

不是笔记软件，不是聊天，不是把 Markdown 换成图数据库。

```text
Canonical   仓库事实源（Frozen K/P/A/M + Lean + Dossier）
  → packages/content（既有 Adapter）
  → packages/domain（K/P/M 投影）
Universe    packages/domain-math（实体 / 关系 / 证据 / 候选 / 时间线）
  → /universe（只读原型）
Frontier    packages/domain-frontier（未知区域 / 研究方向）
Exploration packages/domain-exploration（观察 → 实验 → 失败 → 证明搜索）
```

四层禁止合并。写入 canonical 仍然只经既有 Domain Operation。Universe / Frontier / Exploration **不写仓库**。

探索过程见 [exploration/README.md](exploration/README.md)。
