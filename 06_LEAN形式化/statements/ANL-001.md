# ANL-001

For all integers `x` and `p`, `x p + p x ≤ x^2 + p^2`.

This is the integer algebraic core of Fenchel–Young for `f(x)=x^2/2`
(the factor `1/2` is cleared). It is not the real-analysis conjugate on `ℝ̄`.

- Objects: `Int`
- Quantifiers: forall x p
- Assumptions: none
- Conclusion: inequality
- Boundary: holds for every sign of `p`, including `p ≤ 0`
