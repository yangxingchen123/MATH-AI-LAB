# 数学建模论文模板 v1

本模板只提供**章节骨架**，不是 COMAP 官方 MCM 模板，也不是国赛官方封面。正式提交前请按当年官方格式自行替换 class / 封面 / 控制页。

选用：

- 国赛中文：以 `国赛论文.tex` 为 scaffold，复制到 `04_LATEX/数学建模/国赛/<年份题号>/` 后**重命名**为 `<题>.tex`
- 美赛英文：以 `MCM_paper.tex` 为 scaffold，同样重命名

编译可用 XeLaTeX。正式发布仍走 `python -m tools.latex_build`，且需要用户明确授权。

内容必须能追溯到对应 `07_项目/` 的假设、决策与 Evidence。不得把未跑通的实验写成「模型已经验证」。
