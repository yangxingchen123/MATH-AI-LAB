| 章节 | 对应 Dossier |
| --- | --- |
| 摘要 | 人工结论 + 核心 Claim |
| 问题重述 | `problem.md` |
| 假设 | `assumptions.md` |
| 模型 | `model_selection.md` + Claim |
| 求解与结果 | `experiment_plan.md` + Evidence |
| 敏感性 / 误差 | 诊断与 LIMIT Evidence |
| 优点局限 | `negative_results.md` |
| 参考文献 | `literature.md` |
