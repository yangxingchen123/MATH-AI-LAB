## 1. Purpose / Scope

Phase 3E 目标：在 **不创建新的 editable Learning State Source** 的前提下，建立从 **Validated Source Registries** 机械、确定性派生的 **Derived Learning State** 边界与 provenance 合同。

**3E-0 范围（CLOSED）：**

* Source / Evidence / Derived / Assessment / Recommendation 五层边界  
* 当前合法输入 · Evidence graph · Target granularity  
* Descriptive vs Assessment vs Recommendation 分离  
* Provenance · Determinism · Rebuildability · Automation safety  
* Method / Error Mode 当前排除 · 3D-5E WAITING 不阻塞 baseline  

**3E-0 非范围：**

* 不定义 Assessment enum / numeric mastery  
* 不实现 Derivation Engine / Workspace integration  
* 不创建 `14_学习状态/` · Learning State Validator · Recorder  
* 不修改 Frozen K/P/A/M Schema · 不反写 Source

## 2. Source → Evidence → Derived → Assessment → Action

正式冻结五层模型（**不得混合**）：

| 层 | 定义 | 示例 |
| --- | --- | --- |
| **Source** | Frozen / validated structured objects | K · P · A · M（validated registry entries） |
| **Evidence** | 一次真实 solving / reasoning episode 的可评价记录 | **Attempt**（当前唯一正式 Learning Evidence） |
| **Derived Fact** | 从 validated source / evidence **机械、确定性** 计算出的事实 | `attempt_count` · `outcome_counts` · `last_attempted_at` |
| **Assessment** | 基于 Derived Facts + **显式 assessment policy** 的解释 | 未来可能：`insufficient_evidence` · `needs_review`（**3E-0 不定义 enum**） |
| **Recommendation / Action** | 基于 Assessment + user goal / context 的行动建议 | 未来可能：`next practice` · `review priority` |

**单向传播：** Source → Evidence → Derived → Assessment → Recommendation。  
**禁止 back-write：** Derived / Assessment / Recommendation **不得** 修改 K / P / A / M / 不得创建 Error Mode。

## 3. Current Authoritative Inputs

当前 Derived State **可以合法读取** 的 Validated Registries：

| Registry | 贡献 Learning Evidence? | 角色 |
| --- | --- | --- |
| **Validated Knowledge Registry** | **NO**（非直接 Evidence） | Static object · K↔K relations · 作为 P→K projection 终点 |
| **Validated Problem Registry** | **NO**（非直接 Evidence） | Static object · `knowledge` relation · Attempt target anchor |
| **Validated Attempt Registry** | **YES** | **当前唯一正式 Learning Evidence Source** |
| **Validated Method Registry** | **NO**（当前） | Static object；**无 A↔M formal relation** → 不贡献 learning evidence |

**「可以读取」≠「都能贡献 Learning Evidence」。**

当前 **真正 Learning Evidence Source = Attempt**。

Attempt 已 Frozen 定义：一次 solving / reasoning episode 中，针对 **Problem** 或 **Problem + Frozen part anchor** 的一条独立可评价 Evidence。

## 4. Evidence Target Granularity

### 4.1 Attempt Target Rule（**CLOSED**）

一个 Attempt → **exactly one** evaluation target：

* **whole Problem** — `problem: Pxxxx`，`part` omitted  
* **Problem + exactly one part** — `problem: Pxxxx`，`part: <frozen part id>`

### 4.2 Target-level State 优先（**CLOSED**）

3E baseline **首先** 尊重 Attempt target granularity，形成 **Target Evidence State**。

概念 target key：`Problem` + optional `part`

例如：`P0002` + `part a` · `P0002` + `part b` · `P0002` + whole（若存在 whole-target Attempt）

**Problem-level rollup** = 第二层 Derived aggregation；**不得** 一开始把所有 part Attempts 压成一个 Problem score。

### 4.3 whole vs part 不得混淆（**CLOSED**）

| 规则 | 判定 |
| --- | --- |
| whole-target Attempt（`part` omitted） | 代表 whole-problem target；**不得** 自动拆成 part a/b/c 的独立 Evidence |
| 只完成 part b | **不得** 自动断言 whole P0002 correct |
| part a + part b 各有 Attempt | **不得** 自动合并为 whole mastery |

### 4.4 Correction vs Reattempt（**CLOSED**）

| 概念 | Identity | Derived 计数 |
| --- | --- | --- |
| **Correction** | same A ID · append-only `corrections` | **仍计 1 条 Attempt Evidence**；corrections 数量 **不** 增加 `attempt_count` |
| **Reattempt** | new A ID | 同 target 也计为 **独立** Evidence；`attempt_count` 可 >1 |

Derived computation 读取 **当前 canonical Attempt document**；不得把 correction notes 展开成多条 learning events。

## 5. Descriptive Derived Facts（Layer 1）

**Descriptive Derived Fact** = 可从 validated source **机械计算**、**不表达掌握程度** 的事实。

### 5.1 Outcome — categorical only（**CLOSED**）

Frozen outcomes：`correct` · `incorrect` · `partial` · `unsolved` · `abandoned` · `unassessed`

**禁止** 默认 numeric weights，例如：

```text
correct = 1
partial = 0.5
incorrect = 0
```

**partial ≠ 半正确 / 50% mastery** — 它是 categorical assessment outcome；不同 partial Attempt 完成内容可能完全不同。

**unsolved / abandoned ≠ incorrect** — Derived counters **保留原类别**。

**unassessed** — 无正式 outcome assessment；**不得** 转为 0 · incorrect · weakness。

### 5.2 Assistance — categorical only（**CLOSED**）

Frozen assistance：`independent` · `assisted` · omitted

Derived 可统计：`independent_count` · `assisted_count` · `omitted_count`

**禁止：** `independent = 1` · `assisted = 0.5` 等隐式 scoring。

**assistance omitted ≠ independent** — 表示无可靠 assistance 记录；Derived **保留 omitted 类别**。

**correct + assisted** = 合法 Evidence；**不得** 自动解释为「只算半次成功」。

### 5.3 Safe Target / Problem Descriptive Candidates（**CLOSED**；字段名 DEFER → 3E-1）

Target / Problem 层未来 **候选** Descriptive Facts（**非 Assessment**）：

* `attempt_count`  
* `outcome_counts`（按 categorical enum）  
* `assistance_counts`  
* `attempted_parts` / `target_coverage`  
* `latest_attempted_at` · `latest_outcome`（recency tie-break → DEFER 3E-1）

**Problem-level 禁止直接推导（3E-0）：** `problem_mastery` · `problem_score` · `problem_strength` · `problem_weakness` · `problem_probability_correct` · `problem_review_priority`

### 5.4 Time ≠ Mastery Decay（**CLOSED**）

`last_attempted_at` = Descriptive Fact only。  
**不得** 自动产生「时间久了所以掌握度下降」，除非未来 explicit Forgetting / Assessment Policy 存在。

## 6. Problem / Part Aggregation Boundary

**第一层：** Target Evidence State（Problem ± part）  
**第二层：** Problem-level rollup（仅 descriptive aggregation；**非** mastery）

当前真实 **P0002** 安全 Derived Facts：

| Target | Safe Facts |
| --- | --- |
| **P0002(a)** | `attempt_count = 1` · `outcome partial = 1` · `assistance independent = 1` |
| **P0002(b)** | `attempt_count = 1` · `outcome correct = 1` · `assistance assisted = 1` |
| **P0002 (Problem rollup)** | related Attempt total = 2 · part-level counts 可分别列出 |

**禁止：** `P0002 mastery = 50%` · `P0002 mastered` · `P0002 weak`

## 7. Knowledge Projection Boundary

Knowledge Evidence **不能** 直接来自 Attempt。

**唯一合法 machine-derived projection path：**

```text
Attempt → Problem / Problem Part → Problem.knowledge (formal YAML) → Knowledge
```

即：**A → P → K**

**禁止：**

* body mention · filename · AI semantic guessing → K evidence  
* 因 Attempt 内容「显然涉及线性代数」而自动投影到某 K  

### 7.1 Associated Evidence 语义（**CLOSED**）

通过 A→P→K 聚合的结果，语义上应称为 **Knowledge-associated Evidence**（或等价概念），**不是** 「Knowledge mastery evidence」。

**One Problem correct ≠ All linked Knowledge mastered**

例：Problem `knowledge: [K1, K2, K3]` + Attempt `correct`  
→ 安全推出：K1/K2/K3 各存在 associated Problem Attempt Evidence  
→ **不得** 推出：K1/K2/K3 mastered

### 7.2 P0002 Knowledge Projection（当前仓库）

P0002 当前 **无** formal `knowledge` relation（YAML omitted）  
→ A000001 · A000002 **不得** 投影到任何 K 的 derived evidence count。

### 7.3 draft / reviewed Source lifecycle（**CLOSED**）

Validated ≠ reviewed。  
draft Problem / Method 若 Schema-valid 且含 formal relation，Derived engine **可以读取** 该 formal source relation。  
未来 Assessment 是否要求 reviewed Source → **DEFER**；3E-0 **不** 偷偷过滤 draft。

## 8. Method / Error Mode Current Exclusions

### 8.1 Method（**CLOSED**）

Method Track **COMPLETE**；M0001 · M0002 Frozen + Validated + Workspace-integrated。

但当前 **无 A↔M formal Evidence relation**。

**因此 3E baseline 不得计算：**

* Method usage_count · success_rate · proficiency · mastery · weakness · last_used · recommended Method  

**Discovery provenance ≠ formal Evidence relation**

例：M0002 历史抽象与 A000001 有关 → **不得** 断言「A000001 使用了 M0002」作为 formal derived fact。

### 8.2 Error Mode（**CLOSED**）

Error Mode Schema = **CANDIDATE · NOT FROZEN**  
无 production EM · 无 A↔EM · 无 EM Validator / Registry  

**因此 3E baseline 不得产生：**

* Error Mode frequency · recurrence · last_seen · weakness · review priority  

Error Mode 未来可作为 **enrichment layer**；**不是** 3E baseline prerequisite。  
3D-5E **WAITING FOR REAL ERROR EVIDENCE** **不阻塞** 非-EM Phase 3E baseline。

### 8.3 Derived 不得自动创建 Error Mode（**CLOSED**）

即使 Derived 发现重复 failure pattern → **不得** 自动 create `EM0001`。  
Error Mode creation 仍须 **3D-5E Production Promotion Gate + Content Review**。  
Derived 最多产生 **Error Mode Candidate / Review Signal**。

### 8.4 Automation 不得绕过 Content Review（**CLOSED**）

Method · Error Mode · Knowledge 等 Static Curated Objects：  
自动化可 **发现 candidate · 提示 review**；**不得** 因统计规律自动创建 / 晋升 `reviewed` Source（除非未来另有 governance）。

## 9. Provenance Contract

任何正式 Derived Fact **必须** 能追溯到：

1. **Authoritative validated source IDs**  
2. **明确 derivation path**

例：

* Problem `attempt_count = 2` → provenance: A000001, A000002  
* K-associated Attempt → A000001 → P0002 → Kxxxx（须保留完整 chain）

**若无法回答「这个值从哪些 source facts 算来？」→ 不得作为正式 Derived State。**

**Provenance ≠ Source backlinks** — 不在 K/P/A/M YAML 回填 `derived_from` · `used_by` · `learning_state`。

### 9.1 Output Taxonomy（**CLOSED**）

| 类型 | 含义 |
| --- | --- |
| **DIRECT DERIVED FACT** | 直接来自 Attempt/target 聚合，如 target `attempt_count = N` |
| **PROJECTED DERIVED FACT** | 经 formal relation 投影，如 A→P→K 得 K has N associated Attempts |
| **ASSESSMENT** | 需 explicit policy，如 K needs review |
| **RECOMMENDATION** | 行动层，如 next practice Pxxxx |

Projection **必须** 保留 provenance chain；具体 runtime model → DEFER 3E-1 / 3E-2。

## 10. Determinism & Rebuildability

### 10.1 Derived Learning State 定义（**CLOSED**）

Derived Learning State **不是** Source of Truth。

它是：**Validated Source Registries + 明确 derivation rules** 生成的 **rebuildable · deterministic · non-authoritative** derived state。

**必须满足：**

```text
删除 derived output → 重新计算 → 得到同一结果
```

前提：**Validated Source Snapshot 相同 + Derivation Policy 相同**

### 10.2 Determinism（**CLOSED**）

Same Validated Input Snapshot + Same Derivation Rules → byte/logically equivalent output。

**禁止：** 随机 weighting · LLM 每次自由判断 · 不稳定排序 作为 authoritative Derived State。

**LLM 角色：** 可解释 Derived State · 生成学习建议 · 辅助 Content Review；**不得** 根据自由文本写 authoritative mastery state。非确定性输出 = **Interpretation / Recommendation**，不是 Source-derived fact。

### 10.3 Rebuildability（**CLOSED**）

Derived State 必须：**delete generated files → recompute → same result**  
若无法重建 → 说明含 hidden Source State → **架构违规**。

### 10.4 Derived Cache（**CLOSED**）

3E-0 不设计 persistent cache。  
未来 cache = **disposable · non-authoritative · rebuildable**；**不得** cache → Source of Truth。

### 10.5 No editable Learning State Source Root（**CLOSED**）

**禁止** `14_学习状态/` · `K0001_state.md` · `P0002_state.md` 等人工可编辑 Source files。  
v1 Derived Learning State **不拥有** 新 editable source root。

### 10.6 No Learning State ID Namespace（**CLOSED**）

不需要 `LS0001` · `DS0001`。Target / Problem / Knowledge state 基于现有 Source identities 派生。

### 10.7 Derivation Policy Version（**CLOSED**）

未来 Derived Engine 须有 **versioned · auditable** derivation policy / rule contract。  
**Derivation Policy Version ≠ Source Schema Version** — 不得因 Derived algorithm change 修改 Frozen Source Schema version。  
本轮 **不** 创建 `policy_version` YAML field。

## 11. Automation Safety

### 11.1 Validate Before Derive（**CLOSED**）

```text
Source → Validator → Validated Registry → Derived Computation → Generated View
```

**禁止：** Raw file → Derived State · Generated View → Source

### 11.2 Invalid Upstream → Abort / 0 Writes（**CLOSED**）

Any required upstream validator ERROR → abort derived publish → **0 writes**  
**不得** 部分 Learning State 更新。

### 11.3 Generated Files — No Manual Edit（**CLOSED**）

所有自动生成的 Derived State · Workspace Index · future Learning State View：**NO MANUAL EDIT**。

Derived value 看起来不对 → **Source Correction Flow：**

1. 检查 source 是否错误 → 修改允许的 source → validator → recompute  
2. 或 source 正确 · derivation rule 错误 → 修改 policy/engine → tests → recompute  

**禁止** 直接改 Derived output。

### 11.4 No Synthetic Learning Evidence（**CLOSED**）

禁止为测试 Learning State 在生产 Source 制造 fake Attempts · fake Error Modes · fake Method usage。  
测试 fixture 可有 synthetic records；**生产 Source 绝不能** 为 coverage 制造学习事件。

### 11.5 Sparse Evidence（**CLOSED**）

3E baseline 必须支持 sparse evidence。  
**禁止** 插值 · 补零 · 推测 · 模拟 Attempts 以生成「完整用户画像」。

### 11.6 no evidence ≠ weak（**CLOSED**）

没有 Evidence = **No Evidence** — **不能** 解释为 incorrect · weak · unmastered · `0 mastery`。  
未来 Assessment 可输出 `insufficient_evidence`；**不能用 0 代替**。

## 12. Assessment Boundary（Layer 2）

Assessment Layer **存在**；**3E-0 不定义** 正式 enum · threshold · numeric scores。

**Descriptive Fact ≠ Assessment**

例：`attempt_count = 2` = Descriptive；`mastery = 50%` = Assessment（**3E-0 禁止**）

未来若要发布 authoritative mastery / weakness，**至少** 需要：

1. 明确 Evidence aggregation unit  
2. 明确 outcome semantics  
3. 明确 assistance semantics  
4. 明确 part / whole aggregation  
5. 明确 recency semantics  
6. 明确 evidence sufficiency  
7. 明确 Knowledge attribution  
8. 明确 policy version  
9. 可解释 provenance  

缺一 → **不得** 发布 authoritative assessment。

**禁止（3E-0）：** `0.8 = mastered` · `0.6 = developing` · `mastery_score` · `confidence_score` · `weakness_score`

---

## 13. Recommendation Boundary（Layer 3）

**Assessment ≠ Recommendation**

即使 `assessment = needs_review`，**不** 自动意味着「现在马上复习」。Recommendation 还依赖考试时间 · 课程优先级 · 用户目标 · 可用时间。

Phase 3E 顺序：**Descriptive Facts → Assessment → Recommendation**（不得跳过中间 contract）。

## 1. Design Goal（**CLOSED**）

3E-1 只允许 **两个** 核心 derived model：

| Model | 角色 |
| --- | --- |
| **A. TargetEvidenceState** | **Primary** derived unit — 一个 Attempt target 的描述性 Evidence 聚合 |
| **B. ProblemEvidenceRollup** | **Secondary** deterministic aggregation — 一个 Problem 下所有 target states 的 rollup |

**禁止** 建立 mega `LearningState`（problems · knowledge · methods · errors · mastery · weakness · recommendations · … 合一）。

**3E-1 排除（显式）：** Knowledge projection · Method Evidence · Error Mode Evidence · Assessment · Recommendation · numeric scores · success_rate · temporal recency fields

## 2. TargetKey Contract（**CLOSED**）

### 2.1 Definition

**TargetKey** = derived composite key，**不是** 新 Source identity。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `problem_id` | Frozen Problem ID（`^P\d{4}$`） | Attempt `problem` |
| `part` | `str \| None` | Frozen part anchor；`None` = whole Problem target |

**示例（概念）：**

* `TargetKey("P0002", "a")` — part a  
* `TargetKey("P0002", "b")` — part b  
* `TargetKey("P0002", None)` — whole Problem  

### 2.2 Not a New ID Namespace（**CLOSED**）

**禁止** 创建 `TE000001` · `TS000001` · `LS000001` · `STATE0001` 等 namespace。

TargetKey = existing source identities 的 derived composite key。

### 2.3 Internal Identity vs Display（**CLOSED**）

**Canonical internal concept：** `(problem_id, optional part)` 或等价 immutable model。

**禁止** 将 `"P0002#a"` · `"P0002::a"` · `"P0002/a"` 作为 **唯一 authoritative internal identity contract**（part anchor 未来可能有 representation ambiguity）。

Generated View 可采用 human-readable display string；**display ≠ internal identity**。

### 2.4 Target Validity（**CLOSED**）

Derived layer **信任** Validated Attempt Registry — Attempt Validator 已保证 `problem` valid · `part` valid · target valid。

Derived Engine **不得** 重新实现 Problem existence / part anchor validation。

### 2.5 whole vs part Semantics（**CLOSED**）

| `part` | 含义 |
| --- | --- |
| `None` | whole Problem target（`part` field omitted on Attempt） |
| `str` | exactly one Frozen Problem part anchor |

whole-target Attempt **不得** 自动拆成 part targets；part Attempt **不得** 自动计入 whole target。

## 3. Zero-Evidence Rule（**CLOSED**）

| 情况 | 行为 |
| --- | --- |
| Target 无任何 validated Attempt | **NO TargetEvidenceState**（**不是** `attempt_count=0` 对象） |
| Problem 无任何 validated Attempt | **NO ProblemEvidenceRollup** |
| Part 无直接 targeted Attempt | **NO** `part_attempt_counts` entry；**NO** zero-count materialization |

**No Evidence = absence of Evidence State** — 避免 `attempt_count=0` 被误读为 0 mastery / weak / failed。

**unassessed Attempt：** 仍是 real learning Evidence → **必须** 产生 TargetEvidenceState；`outcome_counts["unassessed"]` 递增。**No Evidence ≠ Unassessed Evidence**。

## 4. TargetEvidenceState v1（**CLOSED**）

### 4.1 Conceptual Field Set（exactly 5）

| Field | Decision |
| --- | --- |
| `target` | **KEEP** — TargetKey |
| `attempt_ids` | **KEEP** — ordered provenance set |
| `attempt_count` | **KEEP** |
| `outcome_counts` | **KEEP** — fixed complete category map |
| `assistance_counts` | **KEEP** — fixed complete category map |

**不含：** problem_title · knowledge · methods · error_modes · score · mastery · weakness · temporal fields · success_rate

### 4.2 `attempt_ids` — Provenance（**CLOSED**）

* **类型概念：** ordered tuple/list of validated A IDs  
* **角色：** Derived provenance · auditability · rebuild verification — **不是** 新 Source relation · **不回写** Attempt  
* **Canonical ordering：** **Attempt ID ascending**（如 A000001 · A000002 · A000010）  
* **不是** chronological order — **禁止** 写「A ID 越大表示发生越晚」  
* **A-ID ascending** 只用于 stable rendering · deterministic provenance representation  

### 4.3 `attempt_count`（**CLOSED**）

# Phase 3E-3 — Knowledge Associated Evidence Projection Contract

**状态：** **DONE**（2026-08-20）  
**Contract name：** **Knowledge Associated Evidence Projection v1**  
**Contract status：** **CONTRACT CLOSED**（Derived Contract · **NOT** Frozen Source Schema）

## 20.1 Purpose

Phase 3E-3 回答两个问题：

1. **在什么条件下**，一条已经 validated 的 Attempt 可以通过 **正式 Source relation** 与某个 Knowledge 建立 **descriptive association**？
2. **Knowledge-associated Evidence** 最小应保存哪些 **Derived Facts**？

**本轮性质：** ARCHITECTURE / DERIVATION CONTRACT DESIGN — **无** production code · **无** Workspace integration · **无** Source Schema 修改。

## 20.2 Terminology — Association vs Assessment

必须严格区分：

| 概念 | 含义 | 3E-3 状态 |
| --- | --- | --- |
| **Knowledge-associated Evidence** | 通过 formal P→K relation 与 Knowledge **建立 association** 的 Attempt 集合及其 categorical counts | **ALLOWED（descriptive）** |
| **Knowledge-assessing Evidence** | 对 Knowledge 本身是否掌握、是否正确、是否薄弱等的 **评价** | **FORBIDDEN（→ 3E-5 Assessment）** |

**核心语义保护：**

> A 与 K 建立 association **绝不意味着**：A independently assessed K · A proved K · A demonstrated mastery of K · K was correct · K was incorrect。

即使 whole Attempt `outcome: correct` 并 association 到 K1、K2，只能说：**与该 K association 的 Attempt 的 source outcome 是 correct** — **不能**说 K1/K2 correct 或 K1/K2 mastered。

## 20.3 Formal Projection Path（v1 唯一合法路径）

3E-0 曾抽象写 **A → P → K**；3E-3 **细化**为：

```text
Eligible Attempt（whole Problem target）
        ↓
Validated Problem
        ↓
formal Problem.knowledge
        ↓
Validated Knowledge
```

简写：**Eligible A → Whole P → P.knowledge → K**

**禁止**笼统写「所有 A→P→K 自动允许 projection」。

| Attempt target | v1 projection |
| --- | --- |
| **whole**（`part` omitted / `TargetKey.part is None`） | **potentially eligible**（须满足 §20.4） |
| **part**（`part` present） | **NOT KNOWLEDGE-PROJECTION ELIGIBLE** |

## 20.4 Projection Eligibility Rule

一个 Attempt **只有同时满足** 以下全部条件，才可形成 A→K associated evidence：

1. Attempt is **Validated**
2. Attempt target is **whole Problem**（`part` omitted / `TargetKey.part is None`）
3. Referenced **Problem is Validated**
4. Problem has formal **`knowledge`**（non-empty validated relation）
5. Referenced **Knowledge IDs are Validated**

**Eligibility 不取决于：** Attempt outcome · assistance · Problem title · Knowledge title · Problem `status` · Knowledge `status`。

## 20.5 Whole vs Part Boundary

### Whole-target Attempt

```yaml
problem: Pxxxx
# part omitted
```

若 `Problem.knowledge: [Kxxxx, Kyyyy]`，该 Attempt **可以分别 association** 到 Kxxxx、Kyyyy（multi-association，§20.10）。

### Part-target Attempt — **NOT ELIGIBLE**

```yaml
problem: Pxxxx
part: a
```

**v1 中 NOT KNOWLEDGE-PROJECTION ELIGIBLE** — 即使 parent Problem 有 `knowledge: [K0001, K0002, K0003]`。

**原因：** `Problem.knowledge` 只声明 **Problem-level formal relation**，**未**声明每个 part 分别依赖哪些 Knowledge。Part Attempt 直接继承全部 Problem.knowledge 会制造 **false association density**。

**原则：** false negative association **优于** false positive formal association（在缺少 Part→Knowledge Source relation 时）。

**Part Attempt 仍完整保留于：** TargetEvidenceState · ProblemEvidenceRollup · `学习证据状态.md` — projection loss **intentional**，非删除 Evidence。

### Future Part→Knowledge — **DEFER**

若未来需要 part-level Knowledge projection，**必须**单独设计 formal relation：`Problem Part → Knowledge`。  
**不得**在 3E-3 修改 Problem Schema（尤其禁止 `parts.a.knowledge` 之类字段）。

## 20.6 Problem.knowledge Semantics

| 情况 | 语义 | Projection |
| --- | --- | --- |
| **`knowledge` omitted** | 当前 Source **未声明** formal P→K relation — **不是** unknown / missing / AI should infer | **NO** Knowledge association |
| **`knowledge: [K1, K2, ...]`**（validated non-empty） | formal P→K relation | whole Attempt **potentially eligible** |
| **`knowledge: []`** | 若 Frozen Schema 已规定 invalid → validated registry **不应出现**；Derived contract **不重新定义** | N/A |

**Body inference 禁止：** 不得读取 Problem Markdown body / title / keywords / embedding / LLM 语义分类推断 Knowledge relation — **只能**使用 validated `Problem.knowledge`。

| Field | Decision | Reason |
| --- | --- | --- |
| `problem_ids` | **DERIVABLE / DROP** | `associated_attempt_ids` → Attempt.problem 可重建 |
| `target_keys` / `targets` / `parts` / `part_counts` | **DROP** | part Attempts v1 不 eligible；provenance 由 A IDs + registries 重建 |

**不保存** `projection_path` · `relation_type` — YAGNI；`associated_attempt_ids` + Validated Registries 可完整重建 formal chain。

## 20.8 Count Invariants

对每个 `KnowledgeAssociatedEvidenceRollup`（K）：

```text
associated_attempt_count
== len(associated_attempt_ids)
== sum(associated_outcome_counts.values())
== sum(associated_assistance_counts.values())
```

**Within-one-K uniqueness：** 同一 K 内，一个 A ID **最多贡献一次**（same A→same K 不得重复计数；重复 → Derived invariant failure / dedupe-required）。

**Assistance：** 禁止 weighting（如 assisted=0.5）— 只保存 categorical counts。

## 20.9 Multi-K Multiplicity

一个 eligible whole Attempt，若 `Problem.knowledge = [K1, K2, K3]`，允许：

```text
A → K1（+1）
A → K2（+1）
A → K3（+1）
```

**Across-K multiplicity 合法** — 每个 K 各贡献一次。

**Knowledge totals 不守恒：**

```text
sum(K.associated_attempt_count)  可能  >  global Attempt count
```

**禁止**用 `sum(K associated attempts)` 当作 global Evidence total — global Attempt total 仍以 **Validated Attempt Registry** 为准。

## 20.10 Provenance

`associated_attempt_ids` 是 **Derived provenance**，**不是**新 Source relation — **不回写** Knowledge / Problem / Attempt。

每一条 A→K association 必须可重建：

```text
A ID
  ↓ Validated Attempt.problem
  ↓ whole-target eligibility（part is None）
  ↓ Validated Problem.knowledge contains K
  ↓ K ID
```

若 formal chain 无法重建 → association **不得存在**。

**Reverse invariant（3E-4）：** 对每个 eligible whole A → P → P.knowledge=[K1…Kn]，A **必须**出现在 K1…Kn 各自 rollup 中。

## 20.11 Zero-Evidence Rule

若某 K **没有任何** eligible associated Attempt → **NO** `KnowledgeAssociatedEvidenceRollup`（**不是** `associated_attempt_count = 0`）。

**不得**遍历所有 K 为每一个创建 zero row — 只 materialize **至少有 1 条** eligible associated Attempt 的 K。

**No Evidence = absence**（沿用 3E-0 / 3E-1 hard contract）。

**unassessed / incorrect / abandoned / unsolved：** 只要是 real validated whole-target Attempt 且 P.knowledge present — **仍 eligible**；只进入相应 outcome bucket。

**incorrect ≠ Error Mode：** 不得自动创建 EM · weakness · Knowledge error association。

## 20.12 Status / Outcome / Assistance Neutrality

| Factor | Affects eligibility? |
| --- | --- |
| Attempt outcome（correct/incorrect/partial/…） | **NO**（只进 counts） |
| Attempt assistance | **NO**（只进 counts） |
| Problem `status`（draft/reviewed/…） | **NO**（Validator PASS 即可） |
| Knowledge `status` | **NO** |

**Validated ≠ Reviewed：** Projection 是 descriptive formal-relation traversal，**不是** content quality assessment。

## 20.13 Explicit Exclusions（v1 DROP FROM DESCRIPTIVE）

**DEFER：** Part→Knowledge · part-target projection · temporal fields · Method Evidence · Error Mode Evidence

**DROP：** success_rate · accuracy · score · mastery · weakness · strength · confidence · coverage · review_priority · recommendation · Assessment enums · Evidence sufficiency threshold（→ 3E-5）

**禁止：** LLM projection · embedding/title/keyword similarity · body inference
