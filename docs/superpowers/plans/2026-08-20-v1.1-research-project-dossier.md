# v1.1 Research Project & Dossier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an auditable and increasingly automated research-project control plane without changing Frozen schemas or existing Normal Operation semantics.

**Architecture:** Canonical project Markdown files remain human-reviewable Source. A dedicated `tools.research_project` package validates local records, performs authorized atomic operations, renders only marked Generated dossier regions, and exposes an isolated CI smoke profile.

**Tech Stack:** Python 3.13, standard library, existing PyYAML dependency, pytest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-20-doctoral-workbench-research-workflow-design.md`

**Baseline (pre-implementation):** tag `v1.0.1-foundation-portability-verified` → `140d01b011ac3b68f3177b9dabcb33b796a6b298`; `pytest` 620 passed; `verification core` PASS; workspace CURRENT / 0 ERROR / 0 WARNING; latex-smoke PASS_WITH_WARNINGS (`UNDERFULL_BOX` ×1).

**Non-goals:** MinerU, solvers, plotting stacks, Lean, RAG, Multi-Agent, Frozen Schema edits, Attempt fabrication, Knowledge auto-promotion, P9 semantic changes.

**Shared vocabulary (must stay consistent across all Tasks):**

| Symbol | Meaning |
| --- | --- |
| `ProjectPath` | `Path` to `07_项目/<name>/` |
| `LocalRef` | `ASM-####` / `CLM-####` / `EVD-####` / `DEC-####` / `NEG-####` |
| `OperationKind` | `WRITTEN` / `NO_OP` / `REJECTED` |
| `OperationResult` | dataclass with `kind`, `message`, `project`, `touched_paths` |
| `ValidationResult` | existing project pattern: `ok: bool`, `errors: list[str]`, `warnings: list[str]` |
| `DataLevel` | `PUBLIC` / `PERSONAL` / `RESTRICTED` |
| `EvidencePolarity` | `SUPPORT` / `OPPOSE` / `LIMIT` |
| `EvidenceKind` | `QUOTE` / `PARAPHRASE` / `INFERENCE` / `COMPUTATION` |
| `DOSSIER_BEGIN` | `<!-- MATH-AI-LAB:RESEARCH-DOSSIER GENERATED BEGIN -->` |
| `DOSSIER_END` | `<!-- MATH-AI-LAB:RESEARCH-DOSSIER GENERATED END -->` |
| `CONTRACT_VERSION` | `"1.1"` |

**Atomic write rule (all mutating ops):** candidate → parse → validate(project) → temporary write → validate(project) → `tools.source_io.atomic.atomic_replace_text` → deterministic `OperationResult`. On any failure, official bytes unchanged.
