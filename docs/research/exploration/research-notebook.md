# Research Notebook 与 Session

## ResearchNotebook

非正式笔记本的结构化替代。

包含：Observations / Questions / Ideas / Attempts / Experiments / Failures / Results

**Notebook 不是 canonical mathematics。** 它是探索史。`notebookIsCanonical` 恒为 false。

Lab 投影条目：`notebook:projected` / `session:projected`。只读，不能写入 `01_知识库/`。

不得把笔记本条目复制进 `01_知识库/` 或当成 Frozen Source。

## ResearchSession

一次研究活动。

`researcher` `goal` `inputs` `actions` `outputs` `events` `conclusion`

例：Investigating generalized topology theorem.

`conclusion` 不是 Theorem。每个 `action` 记录 actor（Human 改假设、AI 生成猜想、Lean 核验证明）。
