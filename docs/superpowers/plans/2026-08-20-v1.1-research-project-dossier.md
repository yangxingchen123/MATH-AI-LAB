## Atomic write rule (all single-file mutating ops)

Use **exactly**:

```python
tools.source_io.atomic.atomic_replace_text(official_path: Path, candidate_text: str)
```

Mandatory flow (no official mutation before the final replace):

```text
parse one-record candidate
→ construct complete prospective file in memory
→ place prospective canonical set in disposable validation tree
→ validate_project(disposable tree)
→ atomic_replace_text(official_path, prospective_text)
→ ResearchProjectOperationResult
```

On any parse / validate / I/O failure: official file bytes **byte-for-byte** unchanged; return `REJECTED` (or raise only in pure helpers such as `assert_decisions_append_only`).

### `init_project` directory publish (not single-file atomic helper)

```text
sibling staging directory
→ write full scaffold into staging
→ validate_project(staging)
→ destination still-absent recheck
→ non-overwriting directory rename/publish
→ on race/conflict → REJECTED + staging cleanup
→ incomplete/conflicting destination → zero change
```

Absent destination → `WRITTEN`. Complete valid scaffold already present → `NO_OP`.

## Research Record Grammar (must match Spec §3 exactly)

### Unique syntax

```text
BEGIN marker
metadata lines
---
body
END marker
```

Concrete form:

```text
<!-- MATH-AI-LAB:RESEARCH-RECORD type=<TYPE> ref=<REF> BEGIN -->
- key: value
---
<body markdown>
<!-- MATH-AI-LAB:RESEARCH-RECORD type=<TYPE> ref=<REF> END -->
```

| Rule | Requirement |
| --- | --- |
| `---` separator | **Mandatory** metadata/body separator (not YAML Schema). No alternate “first non-`- ` line” split. |
| Parser split basis | **BEGIN/END markers only**. Never split on `##` or list lines. |
| Body content | May contain `##` headings, `- list` items, colons, and ordinary Markdown; these **must not** truncate the record. |
| Orphan / nested / duplicate BEGIN / missing END / BEGIN↔END type-ref mismatch | **FAIL** |
| Metadata | lines `- key: value`; key ∈ TYPE required ∪ optional |
| Unknown / duplicate / empty / illegal key format / missing required | **FAIL** |
| TYPE ↔ ref prefix | Must match (`ASSUMPTION`↔`ASM`, `CLAIM`↔`CLM`, `EVIDENCE`↔`EVD`, `DECISION`↔`DEC`, `NEGATIVE_RESULT`↔`NEG`, `GOVERNANCE`↔`GOV`, `AI_CONTRIBUTION`↔`AIC`) |
| GOVERNANCE ref | **Only** `GOV-0001`; `GOV-0002` and any other `GOV-####` **REJECTED** in `parse_local_ref` and/or record validation |
| Unicode / newlines | NFC for content identity; fixtures use **LF** bytes; Decision append-only compares **byte-for-byte** (no whitespace folding) |
| Omission | omitting optional key = key absent; empty-string values illegal |

### Required / optional keys and enums

| TYPE | Required keys | Optional keys | Enums |
| --- | --- | --- | --- |
| ASSUMPTION | `status`, `scope`, `rationale`, `falsifiable_when` | `impacts`, `supersedes`, `superseded_by`, `reviewed` | `status`: `ACTIVE` / `SUPERSEDED` / `RETIRED` |
| CLAIM | `status` | `evidence_refs` (comma-separated EVD refs) | `status`: `OPEN` / `SUPPORTED` / `CONTESTED` / `WITHDRAWN` |
| EVIDENCE | `claim_ref`, `polarity`, `kind` | `source_citation`, `source_sha256` | `polarity`: `SUPPORT` / `OPPOSE` / `LIMIT`; `kind`: `QUOTE` / `PARAPHRASE` / `INFERENCE` / `COMPUTATION` |
| DECISION | `date`, `question`, `options`, `choice`, `basis`, `cost`, `reversible`, `revisit_when` | `opposes`, `evidence_refs`, `supersedes` | `reversible`: `true` / `false`; `date`: `YYYY-MM-DD` |
| NEGATIVE_RESULT | `status`, `failed_route`, `failure_evidence_refs`, `impact`, `retry_when` | `related_claims`, `related_decisions` | `status`: `OPEN` / `CLOSED` |
| GOVERNANCE | `project_data_level`, `external_processing_authorized`, `license_status` | `notes` | `project_data_level`: `PUBLIC` / `PERSONAL` / `RESTRICTED`; `external_processing_authorized`: `true` / `false`; `license_status`: `UNKNOWN` / `LOCAL_ONLY` / `VERIFIED_FOR_EXTERNAL_PROCESSING` |
| AI_CONTRIBUTION | `date`, `role`, `summary`, `human_review` | `tools` | `human_review`: `PENDING` / `ACCEPTED` / `REJECTED` |

External Source rule: if `kind` is `QUOTE` or `PARAPHRASE`, at least one of `source_citation` or `source_sha256` is required.

Template default GOVERNANCE:

```text
project_data_level: PERSONAL
external_processing_authorized: false
license_status: LOCAL_ONLY
```

## Claim–Evidence loop (unique scheme)

1. `add_claim`: `evidence_refs` omitted or empty; must not cite nonexistent EVD.
2. `add_evidence`: candidate is exactly one EVD; `claim_ref` must name an existing CLM.
3. Same atomic `evidence.md` replace: append EVD **and** deterministically update that CLM’s `evidence_refs` (dedupe + stable sort, e.g. ascending EVD number).
4. Validator: every EVD → existing CLM; every CLM-listed EVD exists; EVD.`claim_ref` ↔ CLM backlink consistent; every EVD appears in its CLM’s `evidence_refs`.
5. Never auto-change Claim `status` to `SUPPORTED` / `CONTESTED`.
6. Any failure → entire `evidence.md` byte-for-byte unchanged.

Task 5 and Task 13 **must** include the live regression:

```text
add_claim(no evidence_refs) → add_evidence → Claim backlink updated → validate_project PASS
```

from pathlib import Path
import hashlib
import re
