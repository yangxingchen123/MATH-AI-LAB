# DISC-004

For all natural numbers `n`, the number of odd elements of `{1,...,n}` is `(n+1)/2`
(integer division), which equals `ceil(n/2)`.

- Objects: `List Nat`, `Nat`
- Quantifiers: forall n
- Assumptions: `odds` is the recursive odd-number list in this module
- Conclusion: equality
- Note: this is the classical attained size, not a new bound
