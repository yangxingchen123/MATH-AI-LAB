# 参考资料分类

本目录只保存**原始资料**。解析稿、精读结论、Knowledge 都不以本目录为唯一事实源。

| 子目录 | 用途 |
| --- | --- |
| `教材/` | 书籍、教材扫描件或电子版 |
| `论文/` | 期刊 / 预印本 / 会议论文；一篇一个 `<领域>/<slug>/` |
| `竞赛/` | 美赛、国赛等题面与官方数据包 |
| `讲义/` | 外部课程讲义原件 |
| `_模板/` | 文献条目脚手架，不是资料本身 |

规则：

1. 未分类的文件先放 `00_收件箱/`，分类后迁到这里。
2. 每篇论文写 `identity.md`（可用 `python -m tools.reference_library ingest-paper`）。
3. `derived/` 是 GENERATED。PDF→MD 失败或引擎未装时允许空缺，状态 DEGRADED。
4. 读懂文章（问题 / 方法 / 结论）在 `07_项目/`（`--kind literature`），不在本目录写长文。
5. 审核前不得把这里的摘要复制进 `01_知识库/` 或 `12_方法库/`。
